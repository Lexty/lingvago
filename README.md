# Lingvago — тренажёр механик португальского

Local-first, mobile-first PWA для заучивания механик и правил европейского португальского. Без бэкенда — всё в браузере. Без экзаменов, баллов и оценок.

## Запуск
```bash
pnpm install
pnpm dev        # http://localhost:5173  (пересобирает контент + vite)
# или прод-сборка:
pnpm build && pnpm preview
```
`pnpm content` — пересобрать `public/content.vN.json` (gitignored производный бандл) из `extraction/normalized/*`.

## Что внутри
- **Главная** (`/`) — «Что потренируем?»: шесть механик карточками.
- **Уроки** (`/pack/unit-18`) — пакеты заданий по урокам курса: слова с артиклем, пропуски, фраза по опорам. Новый урок — новый файл `src/packs/unitNN.ts`.
- **Тренажёры** — числа (`/drill/numbers`), спряжение в настоящем времени (`/drill/conjugation`), род и артикли (`/drill/gender`), предлоги (`/drill/preposition`), притяжательные (`/drill/possessive`), вопросительные слова (`/drill/interrogative`). Ответ вводится руками; кнопка «Правило» доступна в любой момент, в том числе до ответа.
- **Справочник** (`/reference`) — карточки правил; из карточки можно перейти к тренажёру этой механики.
- **Данные** (Настройки → «Данные») — резервная копия и восстановление своего прогресса одним JSON-файлом. Всё локально, без аккаунта и сети.

## Структура
- `extraction/` — извлечённые из PDF данные (verbatim + normalized JSON), верификация.
- `scripts/build-content.ts` — контент-пайплайн.
- `src/` — приложение (content, lib, screens, components).
