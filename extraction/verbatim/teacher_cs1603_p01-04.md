### Completar o texto

Todos os dias eu ______ (fazer) os trabalhos de casa para a aula de Português. Eu ______ (ler) textos, ______ (treinar) os verbos ou ______ (escrever) uma composição. **Neste momento** eu estou na aula e ______ (falar) com os meus colegas sobre a família e a professora ______ (escrever) algumas palavras sobre este tema. O meu colega do lado ______ (ouvir) a professora e ______ (tomar) notas.

### Pronomes possessivos (pronome + nome)

| Possuidor | Singular — Masculino | Singular — Feminino | Plural — Masculino | Plural — Feminino |
|---|---|---|---|---|
| Eu | o **meu** amigo | a **minha** amiga | os **meus** amigos | as **minhas** amigas |
| Tu | o **teu** amigo | a **tua** amiga | os **teus** amigos | as **tuas** amigas |
| Você / O senhor / A senhora | o **seu**… | a **sua**… | os **seus**… | as **suas**… |
| Nós | o **nosso**… | a **nossa**… | os **nossos**… | as **nossas**… |
| Vocês / Os senhores / As senhoras | o **vosso**… | a **vossa**… | os **vossos**… | as **vossas**… |

> ⚠️ ✍️ (manuscrito): junto a "Você" alguém escreveu o que parece ser "—vocês—" e junto a "Vocês" parece estar escrito "vosoutros" / "vós outros" (anotação manuscrita do aluno, leitura incerta).

### Nome + determinante possessivo

| Possuidor | Singular — Masculino | Singular — Feminino | Plural — Masculino | Plural — Feminino |
|---|---|---|---|---|
| Ele | o amigo **dele** | a amiga **dele** | os amigos **dele** | as amigas **dele** |
| Ela | o amigo **dela** | a amiga **dela** | os amigos **dela** | as amigas **dela** |
| Eles | o amigo **deles** | a amiga **deles** | os amigos **deles** | as amigas **deles** |
| Elas | o amigo **delas** | a amiga **delas** | os amigos **delas** | as amigas **delas** |

## p03 — Pronomes demonstrativos / Completar com os pronomes demonstrativos

### Advérbios de lugar + Pronomes demonstrativos – invariáveis

| Advérbios de lugar | Pronomes demonstrativos – invariáveis |
|---|---|
| aqui | **isto** |
| aí | **isso** |
| ali | **aquilo** |

### Pronomes demonstrativos – variáveis

| (advérbio) | Singular — Masculino | Singular — Feminino | Plural — Masculino | Plural — Feminino |
|---|---|---|---|---|
| aqui | este | esta | estes | estas |
| aí | esse | essa | esses | essas |
| ali | aquele | aquela | aqueles | aquelas |

### Completar com os pronomes demonstrativos

> ⚠️ ✍️ (manuscrito) sobre o título: por cima de "pronomes" está escrito "determinantes ou", ficando lido pelo aluno como "Completar com os **determinantes ou** pronomes demonstrativos".
> ⚠️ ✍️ (manuscrito) à direita: "de + estas = destas".

**1 –** *Exemplo:* O que é **isso**? **Isto** é um livro.

&nbsp;&nbsp;&nbsp;a) O que é isto?
&nbsp;&nbsp;&nbsp;______ é a camisola da Ana.

&nbsp;&nbsp;&nbsp;b) O que é aquilo?
&nbsp;&nbsp;&nbsp;______ são os sapatos do João.

&nbsp;&nbsp;&nbsp;c) O que é isso?
&nbsp;&nbsp;&nbsp;______ é o telemóvel do Pedro.

&nbsp;&nbsp;&nbsp;d) O que é aquilo?
&nbsp;&nbsp;&nbsp;______ é a mochila da Eva.

**2 –** *Exemplo:* **Este** livro **aqui** é do João.

&nbsp;&nbsp;&nbsp;a) ______ caneta aí é tua?

&nbsp;&nbsp;&nbsp;b) ______ carro ali é o meu.

&nbsp;&nbsp;&nbsp;c) Vou comprar ______ flores aí.

&nbsp;&nbsp;&nbsp;d) Gostas **destas** calças ______?

&nbsp;&nbsp;&nbsp;e) Prefiro **aquela** camisa.

&nbsp;&nbsp;&nbsp;f) Gosto muito **dessa** mala.

**3 –** *Exemplo:* Desculpe, **esta** camisa é de algodão? Não, **essa** é de linho. **Aquela** é de algodão.

&nbsp;&nbsp;&nbsp;a) Maria, este carro é teu?
&nbsp;&nbsp;&nbsp;Não, ______ aí é da Teresa. ______ ali é meu.

&nbsp;&nbsp;&nbsp;b) Este casaco é preto?

&nbsp;&nbsp;&nbsp;c) João, este dicionário é da Ana?

## p04 — Completar o diálogo / Graus dos adjetivos (superlativos)

### Completar o diálogo

Cliente: Essa camisola é de lã?
Empregado: Não, ______ é de algodão.

Cliente: E ______ ali, quanto custa?
Empregado: ______ custa 50€.

Cliente: E ______ aqui, é mais barata?
Empregado: Sim, ______ aí custa só 20€.

Cliente: Ótimo. Então levo ______.
Empregado: Não quer também experimentar ______ ali? É muito bonita.

Cliente: Qual? A preta?
Empregado: Não. ______ que está ao lado. A azul.

Cliente: Está bem. Vou experimentar as duas.

> ⚠️ ✍️ (manuscrito) — anotações/traduções do aluno nas margens:
> - "lã" → *wool*
> - "algodão" → *cotton*
> - "mais barata" → *cheaper*
> - "bonita" → *pretty*
> - "preta" → *black* (com seta), "azul" → *blue* (com seta)
> - No topo da página: "Dias úteis – work days (without week…)" [resto cortado pela margem]

### Graus dos adjetivos – superlativo relativo

| | Superioridade |
|---|---|
| alto | o mais alto |
| lindo | o mais lindo |
| bom / bem | o melhor |
| grande | o maior |
| mau / mal | o pior |

> ⚠️ ✍️ (manuscrito) na coluna da direita, formas de plural acrescentadas pelo aluno:
> - o mais alto → "/ os mais altos"
> - o mais lindo → "/ os mais lindos"
> - o melhor → "/ os melhores"
> - o maior → "/ os maiores"
> - o pior → "/ os piores"

### Graus dos adjetivos – superlativo absoluto analítico

| | |
|---|---|
| alto | **muito** alto |
| lindo | **muito** lindo |
| bom / bem | **muito** bom / bem |
| grande | **muito** grande |
| mau / mal | **muito** mau / mal |

### Graus dos adjetivos – superlativo absoluto sintético

| | |
|---|---|
| alto | **altíssimo** |
| lindo | **lindíssimo** |
| bom | **ótimo** |
| grande | **enorme** |
| mau | **péssimo** |
