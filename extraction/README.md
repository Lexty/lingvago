# Extraction — Passaporte para Português (A1)

Извлечение учебных материалов из image-only PDF-сканов в читаемые/структурированные данные
для приложения по подготовке к экзамену A1.

## Источники (`.local/resources/`)
| PDF | стр. | охват | тип |
|---|---|---|---|
| `..._livro_do_aluno_1.pdf` | 98 | юниты 1–16 (A1) | печатный скан, **без текстового слоя** |
| `..._caderno_de_exercicio_1.pdf` | 44 | рабочая тетрадь A1 | печатный скан, **без текстового слоя** |
| `notebook.pdf` | 25 | рукописные конспекты | скан рукописи |

## Пайплайн
1. **renders/** — оригинальные изображения страниц (`pdfimages`/`pdftoppm`, нативное разрешение).
2. **Канал A — verbatim/** — дословная транскрипция Claude vision (markdown по юнитам), с разметкой блоков, аудио-маркерами 🔊 и флагами неуверенности ⚠️/❓.
3. **Канал B — ocr/** — независимый Tesseract OCR (`por`, локальный tessdata) для авто-сверки.
4. **Канал C** — независимый второй vision-проход (субагенты), поблочное сравнение с A.
5. **verification/** — авто-проверка покрытия (B vs A), непрерывность нумерации, кросс-док; отчёт.
6. **normalized/** — структурированные данные для приложения (countries / grammar / vocab / exercise_templates) + `SCHEMA.md`.

## Статус — ПОЛНЫЙ ПРОХОД ЗАВЕРШЁН (A1, юниты 1–16)
- 153 страницы → 49 дословных файлов (~53k слов) → 7 нормализованных JSON.
- Проверка по 3 осям; исправлено 14 ошибок (каждая выверена по оригиналу/правилам PT).
- App-данные: countries (20), grammar_full (59), vocab_full (665; 247 с родом+артиклем из печатного o/a), exercise_templates_full (31 тип).
- Полный отчёт: `verification/FULL_RUN_REPORT.md`. Очередь: `verification/human_review_queue.md`.
- Пилотный отчёт (юниты 1–2, итеративный цикл): `verification/pilot_verification_report.md`.

## Открытые вопросы
- Аудио-задания (🔊 A1…): большинство имеют не-аудио эквивалент в caderno; финальное решение — TTS pt-PT / замена на чтение-письмо / пропуск.
- Род существительных из рукописи помечен `confidence: medium` — подтвердить по глоссарию учебника.
- Picture-inferred (флаги стран, знаменитости) — сверить с ключами ответов (Soluções) при их извлечении.
