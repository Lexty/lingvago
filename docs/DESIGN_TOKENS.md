# Дизайн-система — «Calm · pastel» (light + dark)

> Зафиксированное направление вёрстки новой версии. Реализация токенов — `designs/tokens.css` (при сборке копируется в `src/styles/tokens.css`). Эталон экранов — `designs/05-calm-expanded.html`.

## Характер
Спокойно, мягко, без стресса (важно перед экзаменом). Мягкие пастельные тона, воздух, скруглённые карточки, **курсивный серив Fraunces** для заголовков + дружелюбный гротеск **Hanken Grotesk** для текста. Нежный градиентный фон. **Без геймификации и без обратного отсчёта дней** (повышает тревожность) — вместо него спокойный «фокус на сегодня».

## Три слоя токенов (правило)
1. **Raw palette** (`--c-*`) — сырые цвета. В компонентах НЕ использовать напрямую.
2. **Semantic** (`--bg`, `--text`, `--primary`, `--accent`, `--cta`, `--danger`, …) — смысл, не цвет.
3. **Component** (`--card-*`, `--btn-*`, `--seg-*`, `--blank-*`, …) — под конкретные элементы.
Компоненты ссылаются только на (2)/(3). Это даёт мгновенную перекраску и тёмную тему «бесплатно».

## Семантическое назначение цвета (важно для консистентности)
- **primary = sage** → прогресс-бары, выбранный уровень L, отметка «сделано», положительное.
- **accent = lavender** → всё интерактивно-«фокусное»: пропуск `___` в задании, теги/чипы статуса, выбранный сегмент (тема/язык). Это «второй» акцент, мягче CTA.
- **cta = success-green** → одна главная кнопка действия на экране («Дальше», «Выгрузить»). Не злоупотреблять — максимум одна на экран.
- **danger/blush** → только фидбэк ошибки (фон blush-soft, текст danger; правильный ответ — жирным цветом текста, не красным).
- **butter** → точечный хайлайт (пилюля «a» в справочнике), эмфаза. Редко.

## Типографика
- **Display:** `Fraunces` (opsz). Заголовки — **курсив 500** (характерная «мягкая» подача). Промпт дрилла — Fraunces 500 прямой.
- **Body:** `Hanken Grotesk` 400/600/700.
- Шкала (моб.): prompt `33` · title `25` (Fraunces italic) · h2-секция `18` (Fraunces italic) · body `15` · small `13` · caption `11.5` (uppercase, tracking `.14em`, muted/warn).
- Межстрочный: тело `1.55`, заголовки `1.1`.

## Радиусы / отступы / тени
- Радиусы: телефон `44`, экран `34`, карточка `20–22`, кнопка `16`, инпут/сегмент `14`, чип `12`, пилюля `999`.
- Spacing scale: `4 · 8 · 11 · 14 · 18 · 22 · 28 · 34` (`--s-1…--s-8`).
- Тени мягкие, «тёплые» в light (фиолетовый оттенок), глубокие в dark. `--shadow-sm/md/lg`.

## Компоненты (рецепты из токенов)
- **Card:** `--card-bg` · `--card-radius` · `--card-shadow` · pad 14–16.
- **Кнопка CTA:** bg `--cta`, fg `--on-cta` (тёмный ink `#0e1a13` в обеих темах — НЕ белый: на light-зелёном `#5aa37a` белый даёт лишь 3.02:1), radius `--r-btn`, `--shadow-sm`.
- **Кнопка ghost:** bg `--surface`, fg `--text`, `--shadow-sm`.
- **Segmented (тема/язык/уровни L):** трек `--seg-track`; активный сегмент темы/языка = `--accent` (`--seg-on-fg`); активный уровень L = `--primary`.
- **Input (ввод предлога):** bg `--surface`, border `--input-border`, focus border `--accent`.
- **Blank `___` в промпте:** bg `--blank-bg` (accent-soft), text `--blank-fg`.
- **Feedback ошибки:** bg `--fb-error-bg` (blush-soft `#fbe9eb`), text `--fb-error-fg` (= `--danger` `#9e4b46`, AA 5.06:1 на этом фоне); правильная форма — `<b>` цветом `--text`.
- **Чекбокс плана:** off — `--check-off-bg`/border `--check-off-border`; done — `--check-on-bg` (sage) + ✓.
- **Pill хайлайта:** «a» = `--highlight` (butter), «para» = `--primary-soft` (sage-bg).

## Состояния
hover — лёгкий подъём (`translateY(-1px)` + усиление тени); active — `translateY(1px)`; selected — `.on` (accent/primary); disabled — `opacity:.5; pointer-events:none`. Фокус-видимость (a11y): обводка `--accent` 2px.

## Тема: Авто / Светлая / Тёмная (SPEC §10.4)
- `tokens.css`: `:root` = light; `[data-theme="dark"]` = dark; `@media (prefers-color-scheme: dark)` без принудительного `data-theme` = тёмная (для «Авто» без JS).
- Рекомендуемая логика выбора (сохраняется в localStorage):
```js
// pref: 'auto' | 'light' | 'dark'
function applyTheme(pref){
  const root = document.documentElement
  if(pref === 'auto') root.removeAttribute('data-theme')   // следуем системе (@media)
  else root.setAttribute('data-theme', pref)               // принудительно
  localStorage.setItem('lg.theme', pref)
}
applyTheme(localStorage.getItem('lg.theme') || 'auto')
```
- Язык (RU/EN) — независимо: по умолчанию системный, fallback EN, ручной переключатель (SPEC §10.4).

## Как применять
1. Импортировать `tokens.css` первым в `src/styles/`.
2. На корне приложения держать `--mesh` как фон экрана/шелла.
3. Все компоненты — только через semantic/component токены; новых «голых» hex в компонентах не вводить (расширять палитру здесь).
4. Подключить шрифты: `Fraunces` (ital, opsz) + `Hanken Grotesk` (400/500/600/700/800).

## Не-цели дизайна
Геймификация (очки/стрики/лиги), обратный отсчёт дней, агрессивные цвета/контраст, плотные «дашборд-аналитики» на главной. Спокойствие и ясность важнее «вовлечённости».
